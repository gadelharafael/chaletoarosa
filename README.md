# Guia do Hóspede — Chalés Toá Rosa

Clone do guia publicado em `floresdocerradoecoresort.github.io`, com a identidade visual dos **Chalés Toá Rosa · Vila de São Jorge**.
Página estática única (`index.html`) — abre direto no celular, sem servidor.

## Temas (botão "Tema")
- **Rosé aquarela** (padrão, claro)
- **Folhagem** (verde escuro)
- **Telha & madeira** (marrom/terracota)
- **Entardecer** (ameixa/rosa)

## A PREENCHER com a pousada (tudo em aberto)
Edite `index.html` e procure por:
- `5500000000000` → WhatsApp / telefone da recepção (links `wa.me` e `tel:`)
- `A PREENCHER` → exibição do número, nome e senha do Wi-Fi
- `--:--` → horários de check-in e check-out
- Coordenadas da pousada (`"resort": {"lat": ..., "lon": ...}` e links `-14.1962...,-47.8491...`) e as distâncias/pinos dos mapas, que ainda são do ponto de partida original
- Textos das páginas *O chalé*, *Regras*, *Importante* e *FAQ* (estão genéricos)
- URL do site em `og:url` / `canonical` (`gadelharafael.github.io/chaletoarosa`)

Conteúdo regional (cachoeiras, trilhas, restaurantes, clima, hospitais) foi mantido: a região é a mesma, Vila de São Jorge.

## Publicar no GitHub Pages
Crie um repositório novo (ex.: `gadelharafael.github.io/chaletoarosa`), envie estes arquivos e ative Pages na branch `main`.
